# AKOREDE VITA Interface Prototype

This directory contains the first responsive, interactive product-interface prototype for AKOREDE VITA.

## Run it

Open `index.html` in a modern browser. It has no build step and uses no external runtime dependencies.

## Included

- Responsive desktop sidebar and mobile bottom navigation
- Demo game library with search and filters
- Sample title details
- Controller and settings preview screens
- Explicit status messaging that the emulator core is not connected

## Important status

This is a **UI prototype only**. It does not emulate PlayStation Vita software, scan installed games, configure real controllers, or access emulator services. The catalogue entries are fictional placeholders. Do not treat the prototype as a functional emulator or release build.

## Next engineering steps

1. Review the UI on a phone-sized and desktop-sized viewport.
2. Finalise the native UI technology and platform-specific integration boundaries against the audited Vita3K architecture.
3. Port the approved product experience into the appropriate Windows and Android application layers.
4. Connect library, input, settings, and diagnostics to real emulator interfaces only after the compliant upstream integration baseline is established.
